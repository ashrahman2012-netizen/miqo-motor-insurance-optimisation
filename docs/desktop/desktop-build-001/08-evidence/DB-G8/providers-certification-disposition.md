# DB-G8 Providers and Certification disposition

## Providers — DEFERRED

The current authoritative model can expose provider/route/channel/adapter/mapping identity only as part of a persisted exact decision trace.

That evidence does **not** establish a global provider state such as:

- live;
- enabled;
- healthy;
- certified;
- commercially active;
- available for real quotation.

The DB-G8 Providers route therefore:
- states that global provider status is unavailable;
- allows navigation to exact Selection-linked provider evidence;
- exposes no activation/deactivation control;
- makes no health or certification inference.

## Certification — DEFERRED

No authoritative certification resource or certification artefact is admitted to Desktop Admin.

The route may show packaged runtime identity as engineering context, but explicitly does not convert any of the following into certification:

- repository CI success;
- Desktop G7/G8 success;
- TEST/SYNTHETIC installed-package proof;
- deterministic TEST OIDC authentication;
- synthetic quotation/provider evidence.

Production signing, real IdP registration, non-synthetic environment authority, provider activation and release governance remain external/downstream controls.

**Closure:** both navigation areas are truthful controlled-deferred surfaces; no fake status data is created.
