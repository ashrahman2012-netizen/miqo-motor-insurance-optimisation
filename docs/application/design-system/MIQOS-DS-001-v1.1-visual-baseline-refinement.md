# MIQOS-DS-001 v1.1 — Visual Baseline Refinement

**Status:** FROZEN FOR APPLICATION BUILD  
**Primary visual authority:** MIQOS - UX Design Sample supplied 20 September 2026.

## Governing rule

Blue communicates interaction. Green communicates success. Amber communicates attention. Red communicates failure. Purple is reserved for specialised/system semantics.

The existing functional screen references remain the authority for page structure and information hierarchy. The v1.1 design system controls visual execution. Existing application semantics, F/V/D/O/I boundaries, environment rules, comparison rules and non-advised terminology are unchanged.

## Application retrofit

The runtime shared shell and semantic primitives inherit v1.1. BUILD-001A through BUILD-001E remain behaviourally certified; their visual layer is refined without changing pricing, optimisation, normalisation, comparison, recommendation or provider behaviour.

BUILD-001D specifically uses blue for selected objectives and Generate Scenarios, green only for READY/success outcomes, amber for applicability warnings, red for rejected combinations and neutral/special accents for provenance.

BUILD-001E uses blue for comparison controls and actions, green for DIRECTLY_COMPARABLE/eligible success states, and keeps adjusted/not-comparable evidence visually calm and out of the ranked set.
